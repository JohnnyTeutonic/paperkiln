  proves it — so `Delta(b) = A - D(b)` with `A >= 0` by construction.

  `W ~= 2t*SD/(sqrt(n)|slope|)`, says a finite seed budget always leaves
  an interval where the question has no answer.

  is now in the seed-lottery exhibit.

## The habit that paid off

Testing each pre-registered analysis **before its data existed** caught
three errors that would have produced wrong published verdicts: the
transfer gate could not read lanes at all; the long-budget rule would
have called a *first* crossing a *second* (reporting the theorem
falsified on data that never falsified it); and F1 had never been shown
capable of firing positively. None of these are visible once the data is
in — you would simply have gotten a verdict.
